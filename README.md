# fsd-p6

A React product store demonstrating props, component state, events, and Sass styling.

## Run locally

```sh
npm install
npm start
```

The app runs at [http://localhost:3000](http://localhost:3000).

## Verify

```sh
npm test -- --watchAll=false
npm run build
```

## Screenshots

Screenshots of the initial store, added product, and updated cart are in [`outputs/screenshots`](./outputs/screenshots).
